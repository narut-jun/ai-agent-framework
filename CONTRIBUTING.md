# Contributing to Ai-Agent-Framework

Thank you for your interest in contributing to **Ai-Agent-Framework**! 

This framework is designed to help developers manage AI agent knowledge, memory, and project scaffolding effectively. We welcome contributions from the community to make it even better.

## 🤝 How You Can Contribute

There are several ways to contribute to this project:

1. **Translations**: Currently, most guides (`guides/`) are in Thai. We highly welcome PRs translating these into English.
2. **Cross-Platform Scripts**: The current CLI scripts (`scripts/`) are written in PowerShell for Windows. Bash/Zsh scripts for macOS and Linux are greatly needed.
3. **Bug Reports & Feature Requests**: Open an issue if you find a bug or have an idea for a new feature.
4. **Documentation**: Fixing typos, improving explanations, or adding examples.
5. **IDE Configurations**: Adding support for new AI coding assistants or improving existing configuration templates (`templates/project-template/`).

## 🛠️ Contribution Workflow

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/ai-agent-framework.git
   ```
3. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes** and test them (if applicable).
5. **Commit your changes** using clear and descriptive commit messages:
   ```bash
   git commit -m "feat: add bash script for project creation"
   ```
6. **Push to your fork**:
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Submit a Pull Request** against the `main` branch of the original repository.

## 📝 Coding Standards

- **Scripts**: Ensure scripts are well-commented and include proper error handling.
- **Documentation**: Keep the tone professional, concise, and easy to understand. Use Markdown formatting effectively (tables, code blocks, bolding).
- **Templates**: Ensure templates remain generic. Do not include personal data or specific project names.

## ❓ Need Help?

If you have any questions or need guidance, please open an issue with the tag `question`.

Thank you for making Ai-Agent-Framework better!
